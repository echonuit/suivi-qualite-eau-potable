# Fichiers de test

Rangez ici les cas réels qui servent à vos tests : quelques résultats tirés de l'API Hub'Eau (une série de nitrates, une série de `<0,02`, un paramètre à plage comme le pH), quelques lignes du catalogue E-Phy. Le sujet le dit dans ses « Repères techniques » : c'est avec des cas réels que les tests ont le plus de valeur.

Donnez à chaque fichier un nom qui dit ce qu'il contient, par exemple `nitrates-aix-couteron.json`.

Git conserve ce dossier à l'octet près (voir `.gitattributes`), et votre éditeur n'y corrige ni l'encodage ni les fins de ligne (voir `.editorconfig`). C'est voulu : un extrait retouché ne ressemble plus à ce que l'API ou le catalogue renvoient vraiment.

Gardez ces extraits petits, quelques dizaines de lignes. Les archives annuelles de data.gouv.fr et le catalogue E-Phy complet ne vont pas dans le dépôt : ils se retéléchargent.
